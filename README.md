# chat_websocket

Минималистичный чат на WebSocket: Node.js-сервер (библиотека `ws`) + статичный фронтенд без сборки.

## Требования
- Node.js 18+ (LTS)

## 1. Установка зависимостей
```bash
npm install
```
> Если предпочитаете Bun — `bun install`.

## 2. Запуск сервера
```bash
npm start
```
Сервер слушает WebSocket-порт **8000** (`ws://127.0.0.1:8000`).
- Команда использует `nodemon`, поэтому при изменении кода сервер перезапускается автоматически.
- При первом запуске `npx` предложит установить `nodemon` — подтвердите (`y`).
- Без автоперезапуска: `node server.js`.

## 3. Открытие чата в браузере
При запущенном сервере просто откройте файл **`index.html`** в браузере (двойной клик). В окне появятся два клиента, которые обмениваются сообщениями через WebSocket.

Если удобнее через HTTP-сервер:
```bash
npx serve .
```
и откройте указанный адрес.

## Остановка
`Ctrl+C` — сервер остановится, история сообщений сохранится в `log.json`.
